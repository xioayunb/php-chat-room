# PHP 单文件聊天室

[![PHP Version](https://img.shields.io/badge/PHP-5.6%2B-blue.svg)](https://php.net)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![No Database](https://img.shields.io/badge/Database-None-orange.svg)]()

一个功能完善的单文件PHP聊天室，无需数据库，适合虚拟主机部署。

## 功能特性

- **用户昵称设置** - 支持自定义昵称，本地存储
- **实时消息收发** - AJAX轮询，2秒刷新
- **在线用户列表** - 右侧显示当前在线用户
- **表情包支持** - 内置100+ emoji表情
- **图片发送** - 支持通过URL发送图片
- **聊天记录导出** - 一键导出为txt文件
- **管理员系统** - 密码登录，可删除消息/清空记录
- **禁言功能** - 按IP禁言用户
- **响应式设计** - 适配手机和桌面

## 🤖 AI 自动回复

内置 AI 聊天机器人，**零配置开箱即用**：

- **内置免费接口**（默认）：Pollinations 文本接口，无需注册、无需密钥。
  ⚠️ 免费服务有限流，可能间歇性返回 402（此时该轮自动跳过，不影响聊天室）。
- **OpenAI 兼容接口**（推荐，稳定）：管理面板「AI 回复设置」→ 接口类型切换，
  填入任意服务商地址+密钥即可，如：
  - DeepSeek：`https://api.deepseek.com/v1/chat/completions`（注册送额度）
  - OpenRouter：免费模型众多
  - 本地 vLLM / Ollama：完全离线

管理面板可配置：

| 配置项 | 说明 |
|---|---|
| 接口类型 | 内置免费 / OpenAI 兼容 |
| API 地址 / 模型 / 密钥 | 密钥加密存储、不回传前端 |
| **AI 人设** | 自定义性格与说话风格（如"傲娇猫娘"） |
| AI 昵称 | 聊天室显示名，带专属 `AI` 徽章 |
| 触发方式 | `被 @ 时才回复` 或 `每条新消息都回复` |
| 上下文条数 | 2-30，AI 能记住最近对话 |

「测试 AI 连通性」一键验证配置。自动防重复回复；单条脏数据不会破坏聊天记录。

## 部署要求

- PHP 5.6+ (推荐7.0+)
- 无需数据库
- 目录写入权限 (755 或 777)

## 安装步骤

1. 将 `index.php` 上传到网站目录
2. 确保目录有写入权限
3. 访问域名即可使用

## 管理员设置

编辑 `index.php` 第14行修改密码：
```php
$admin_password = "你的新密码";
```

默认密码: `admin123`

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.php` | 主程序文件 |
| `data/*.json.php` | 数据文件（自动创建，带自毁头，无法被直接下载） |
| `data/.htaccess` | Apache 访问保护（自动创建） |

## 技术栈

- **后端**: PHP (单文件，无框架)
- **前端**: HTML5 + CSS3 + JavaScript (原生)
- **数据存储**: JSON文件 (无需数据库)
- **通信**: AJAX轮询

## 安全特性

- XSS防护 (HTML转义)
- SQL注入防护 (PDO预处理语句)
- **数据防下载**：数据文件存于 `data/` 目录且为 `.php` 后缀，内容以 PHP 自毁标记开头——即使服务器未配置任何保护规则，直接用 URL 访问数据文件也只会得到空白页；Apache 下另有 `data/.htaccess` 双保险
- **IP 不可伪造**：仅取 `REMOTE_ADDR`，禁言无法通过伪造 `X-Forwarded-For` 绕过
- **并发安全**：写操作采用「临时文件+原子重命名」+ 全局互斥锁，高并发下不再丢消息/坏数据
- **验证码防爆破**：错误5次作废；发送限速60秒/封；使用密码学安全随机数
- **管理员防爆破**：连续输错5次锁定10分钟
- **消息ID防撞号**：时间戳基准，清空记录后也不会覆盖数据库历史消息
- 消息撤回改为标记式（显示"已撤回"占位），与界面渲染一致
- 在线用户列表自动清理7天不活跃记录
- 旧版本根目录裸 JSON 数据文件会自动迁移到新结构并将原文件失效化

### Nginx 用户注意

Nginx 不读取 `.htaccess`，但由于数据文件是 `.php` 后缀且自带 exit 自毁头，默认配置下同样无法被下载。如需更严格，可在站点配置中添加：

```nginx
location ~ ^/data/ { deny all; }
```

## 升级说明

用新版 `index.php` 覆盖旧文件即可，首次访问时自动完成：
1. 根目录旧的裸 JSON 数据 → 迁移至 `data/*.json.php`
2. 旧数据文件立即失效化，防止残留泄露
